# homebrew-tap

Homebrew tap for [eureka-cli](https://github.com/loprx/eureka-cli) and [DiscMate](https://github.com/loprx/discmate).

## Install

```bash
brew install loprx/tap/eureka-cli
```

To install DiscMate on Apple Silicon with macOS 13 or later:

```bash
brew tap loprx/tap
brew install --cask discmate
```

DiscMate is an experimental, ad hoc signed app. If macOS blocks its first launch, approve it in System Settings → Privacy & Security → Open Anyway. See the [DiscMate README](https://github.com/loprx/discmate#readme) for tested media and limitations.

## Update

```bash
brew upgrade loprx/tap/eureka-cli
```
